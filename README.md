# Application Verifying Writing Authenticity 

This repository contains the application prototype for the thesis **Development of an Application Verifying Writing Authenticity**.

The goal of the project is to develop a browser-based system that supports the review of writing authenticity by analysing writing-process metadata. Instead of relying only on the final submitted text, the application focuses on how the text was produced: typing activity, paste events, editing behaviour, pauses, session duration, and revision patterns.

The system is intended to provide contextual evidence for teachers or reviewers. It should not make automatic accusations or act as a standalone AI detector.

## Thesis Context

The thesis investigates the limitations of traditional AI-generated text detection methods and proposes a process-based approach to writing authenticity. Existing AI detectors can produce unreliable results, false positives, and biased outcomes, especially when used as the only basis for judgement.

This prototype explores whether writing-process metadata can provide more transparent and useful evidence. The planned application combines:

- a Chrome extension for collecting writing-session metadata
- storage for writing events
- basic behavioural analysis
- a dashboard or review view for inspecting writing sessions
- evaluation using controlled writing scenarios

## Planned MVP

The minimum viable prototype should be able to:

1. Start and identify a writing session.
2. Capture basic writing activity without storing the full written text.
3. Detect typing events.
4. Detect paste events.
5. Detect deletion or editing behaviour.
6. Store event metadata.
7. Calculate simple session metrics.
8. Display a session summary for review.

Possible session metrics include:

- total writing time
- typed character count
- pasted character count
- paste-to-type ratio
- number of editing events
- long pauses between writing events
- session start and end times

## Evaluation Plan

The prototype will be evaluated using three controlled writing scenarios:

1. **Human-written text**  
   A participant writes text naturally without AI assistance.

2. **AI-generated text pasted into the document**  
   A participant pastes generated text directly into the writing environment.

3. **AI-generated text manually retyped**  
   A participant manually types text that was generated by an AI system.

The purpose of the evaluation is to compare behavioural patterns between scenarios. The system is not expected to prove authorship with certainty.

## Privacy and Ethics

Because writing-process metadata can be sensitive, the application should follow privacy-by-design principles:

- collect only metadata needed for behavioural analysis
- avoid storing full document content unless necessary
- make monitoring visible and understandable to users
- use results as supporting evidence for human review
- avoid automatic accusations or final integrity decisions

These principles are important for aligning the prototype with GDPR-related concerns discussed in the thesis.

## Project Scope

This project is a thesis prototype, not a production-ready monitoring system. The main purpose is to design, implement, and evaluate a working artefact that demonstrates how writing-process metadata could support authenticity review in educational contexts.
